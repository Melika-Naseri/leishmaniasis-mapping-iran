GIS-Based Mapping of Leishmaniasis in Iran (2023)

Overview

This project presents a geographic visualization of leishmaniasis distribution across the provinces of Iran in 2023.

Methodology

Epidemiological data were extracted from a previously published source, organized using Microsoft Excel, and visualized using ArcGIS Pro.

My Contributions

- Extraction and organization of epidemiological data.
- Preparation of the dataset in Microsoft Excel.
- Integration of epidemiological data with provincial geographic boundaries.
- Creation of a thematic map using ArcGIS Pro.

Tools
